# User Management Dashboard

A user management application built with React, TypeScript, and Redux Toolkit

## Live Demo

[View Live Demo](https://user-management-dashboard-tau-brown.vercel.app/)

## Features

- Fetch users from the JSONPlaceholder REST API
- Display user information in reusable React components
- Search users by name
- Sort users alphabetically (A–Z / Z–A)
- Filter the user list (all users / first five users)
- Add new users through a controlled form
- Persist manually added users using localStorage
- Handle loading and error states

## Tech Stack

- React
- TypeScript
- Redux Toolkit
- React Redux
- Vite
- HTML5 / CSS3
- Fetch API
- localStorage

## API

User data is fetched from [JSONPlaceholder](https://jsonplaceholder.typicode.com/users)

New users are stored locally in the browser using `localStorage` and are not sent to the API

## Project Purpose

This project was created to practice React, TypeScript, Redux Toolkit, asynchronous data fetching, state management, and browser storage
